# 旁白分析

有的频道画面很简单，靠旁白撑起整条视频：处境、数字、感受、观点都在旁白里讲。分析这类频道时，旁白就是报告重点，要单独做一块“旁白分析”，不能只在器材页里带一句（用户要求，2026-10-25，kiki in China：旁白占 78% 时长，每分钟 133 词，约是 Zaza、Gangzi 的 3 倍）。

## 1. 先判断是不是旁白型频道

每个频道都跑一遍 `narration_stats.py`，几秒钟就跑完，字幕在做人物背景时已经下好了：

```bash
python3 $S/narration_stats.py $W/data/<handle> --subs $W/subs --comments $W/comments \
  --titles $W/titles_zh.json --name <网名> --out $W/out/narration.json --slides $W/out/narration_slides.json
```

**第 0 步：旁白是不是本人的声音？**（用户纠正，2026-10-25，Hey KaKa：旁白占 63%，我当成“本人照稿念、旁白是核心”，其实她对镜头只会说“I got off of school”这类有口音的短句，长段旁白明显是 AI 配音，频道的看点是爸爸和一家人。）
- 在字幕里找 `>>` 换人标记：自动字幕会把本人对镜头说话和旁白标成两个人；对应时间点抽帧，确认她正对镜头说话。
- 比较两种声音的英语水平：本人短句、语法错、口音重，旁白长句、书面、全写 do not / I am、零口头语 → AI 配音（推断，频道没承认时标推断）。
- “Is not it”这类拆错的缩写被原样念出，是 AI 照字朗读的线索，不是本人念错。音高接近不能排除声音克隆。
- 判为 AI 配音时：不做「旁白分析」一块，只在「拍摄手法」末尾放两页（`images` 本人 vs 旁白截帧对比；`rows` 几条线索），人设页别写“英语是强项”，启示里写“英语不够，AI 配音补”。

确认是本人声音后，再看抽帧统计（见 gear.md 的“单人频道的镜头归类”），满足下面两条就算旁白型，做完整的「旁白分析」一块：
- 旁白占全片时长 **60% 以上**；
- 博主对着镜头说话的画面（自拍、对镜头讲）**不到 30%**。

不满足时只在「拍摄手法」里放一页“原声还是旁白”。用户直接说“重点分析旁白”时，不看这两条，照做。

## 2. 脚本给出的数字

| 指标 | 怎么算 | 怎么读 |
|---|---|---|
| 旁白占比 | 自动字幕逐词时间，词间隔小于 1.2 秒算连续说话 | 越高越说明画面只是配图 |
| 每分钟词数 | 词数 ÷ 时长 | 各条的范围很窄（例如 120–146），说明是照稿念 |
| 播放前 3 条的中位数 | 和别的频道比时用这个口径 | 之前做过的报告在 `~/youtube-*-report-*/out/narration.json` 里，直接拿来比 |
| 口头语 | uh / um / erm / hmm，每千词几个 | 即兴说话通常每千词 10 个以上；kiki 是 0.2 个，基本可以判断是念稿 |
| 过去时 | “I was / I went / I decided…” | 某条特别多（相亲角 55 处），说明是事后回顾着写的稿，不是现场边走边说 |
| 其他人说话 | 字幕里的 `>>` | 有这些段落的地方是现场同期声，可以单独说明 |
| 模板环节 | 钩子开头、自我介绍、报金额、换算美元、报时间点、向观众提问、结尾告别 | 每个环节出现在几条里 |
| 直译候选 | 脚本内置的中式说法和主谓不一致 | 只是候选，要回到上下文人工判断 |
| 评论反应 | 夸声音 / 英语、怀疑 AI 配音、替她说是本人、问写稿 / 翻译 | 再加博主本人关于口音、配音、写稿的回复 |

和其他频道比语速时，**优先用油管自动字幕**。用 whisper 自己转写时，长段落容易反复卡在同一句（曾经有一条视频一句话重复了 105 次，把真实旁白吞掉了）：加 `--condition_on_previous_text False`，转完检查有没有连续重复的句子。

## 3. 判断旁白怎么做出来

用户常见的推测是“中文写稿 → 翻译成英文 → 本人念 → 后期配上去”。每一步单独找证据，标“有证据”或“推断”：

| 环节 | 有证据的情况 | 只能推断的情况 |
|---|---|---|
| 照稿念 | 口头语极少、语速稳定；念错的地方能看出是照着书面句念的（kiki：“…now I spend most of **her** time”，书面长句里的代词没改过来） | 只有“听起来很顺” |
| 本人的声音 | 博主自己回复过口音（“藏不住中国口音”）；有观众指出她会念错词（AI 能模仿口音，但不会念错） | 只有观众说“像 AI”或“不像 AI”，这些都只是线索 |
| 后期配音，不是同期 | 旁白占比远高于对镜头画面占比（78% 对 11%）；旁白在她吃东西、离镜头很远、背对镜头时还在继续；大量过去时回顾 | 只看了少数几段 |
| 先写中文再翻译 | 博主自己说过 | 中文说法被直译（“透明人”→ a transparent person，“一百块也是钱”→ 100 RMB is still 100 RMB，“应届生”→ fresh graduate）；句式整齐、书面化。博主没承认时一律标“推断” |
| 字幕 | 截帧里每一帧底部都有字幕，就是烧录字幕；中文对话配中英双语 | — |

评论里有人问“你是不是先写中文再翻译”，博主没回的，在备注里写明“没有回应”，不要当成默认。

## 4. 页面（插在「拍摄手法」后面，开一个「旁白分析」分节）

| 页 | 类型 | 内容 |
|---|---|---|
| 旁白是核心 | `stats4` | 旁白占比、语速、总词数、口头语；bullets 写“画面是配图”“照稿念” |
| 旁白量对比 | `table` | 和其他频道比每分钟词数（播放前 3 条中位数），加“是它的几倍”和“特点”列 |
| 旁白怎么做出来 | `rows` | 中文写稿 → 译成英文 → 本人照稿念 → 本人声音 → 后期配音 → 烧录字幕，`tag` 写“有证据 / 推断” |
| 证据 | `cards` | 6 张：直译的说法、念错的地方、过去时最多的一条，`note` 写出处视频 |
| 模板 | `rows` | 每个环节一行，`desc` 引一句原话，`tag` 写“x / 10” |
| 观众反应 | `panels` | 夸声音 / 英语的人数 vs 怀疑 AI 的条数，`box` 写博主怎么回应 |

`--slides` 会生成前面这几页的草稿（stats4、逐条表、模板、观众反应），把（…）占位符换成结论和原话。“旁白怎么做出来”和“证据”两页要人工写。视频版照常只放关键词，例如把证据卡片写成“transparent person ← 透明人”。

旁白型频道的其他页也要跟着改：
- 「拍摄手法」最后加一页“拍法简单也能成立：画面配图，旁白讲故事”（`three_cols`：画面 / 旁白 / 门槛）。
- 人设页不要写“语速慢”这类没量过的话，用量出来的数字。
- 「启示」里加一条“先写稿，再配旁白”。
