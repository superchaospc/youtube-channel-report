# 拍摄器材与拍摄方式

YouTube 不公开相机型号这类元数据，所以器材只能从外部找证据，再加上推断。这一页要讲清楚三件事：**他怎么拍**（拍摄方式统计）、**大概用什么拍**（器材推断，每条都写依据）、**门槛有多高**（一句总结）。

## 1. 收集证据

```bash
python3 $S/gear_scan.py $W/data/<handle> --out $W/gear [--proxy socks5://127.0.0.1:1091]
```

脚本默认抽样播放量最高的 8 条 + 最新的 4 条，因为器材可能中途换过。它会做四件事：
- **扫描简介**：所有长视频的简介和频道简介，找器材词和带货链接（amzn.to、kit.co 等）。很多频道的简介里根本不写器材，扫不到是正常的。
- **扫描评论**：抽样视频的一级评论，找器材类关键词和拍摄方式类关键词（camera angles、tripod、POV、subtitles、editing、AI voice、own voice）。
- **下载截帧**：YouTube 自动从视频中间截的帧（maxres1–3，没有就用 hq1–3），每条视频 3 张，拼成带编号的联系表 `sheet-N.jpg`，编号对应 `evidence.md` 里的视频。
- **技术参数**：用 yt-dlp 读分辨率、帧率、是否 HDR。本机被 YouTube 判定为机器人时，要加 `--proxy` 走隧道（见 data-gotchas.md）。

## 2. 看截帧，逐帧归类

打开每张联系表，给每一帧归一类，最后计数：

| 类别 | 判断方法 |
|---|---|
| 手持自拍（广角近景） | 人脸占画面大块、广角透视、背景在动 |
| 固定机位（三脚架 / 桌面） | 镜头不动、能看到全身或整张桌子、博主走进走出画面 |
| 第一视角 | 只看到手和手里的东西，或者从胸前、头部往下拍 |
| 车载 / 运动机位 | 固定在车把、头盔或车身上 |
| 别人帮忙拍 | 远景跟拍，或者博主和别人同时在画面里活动 |
| 空镜 / 风景 | 没有人，只有环境 |

再顺手记下：画面里能看到的器材（手机、麦克风、腕带、支架），字幕的样式，有没有旁白。

**找倒影**（用户教的，最有力的证据）：博主拿手机对着镜头、照镜子、戴眼镜、站在玻璃窗或黑屏前时，倒影里常能看到相机本体，比如镜头数量和排列、云台形状、机身大小。自动截帧未必截到，看到这类镜头就去视频里定位放大。用倒影认出的机型要对照发售日期：只能说明发售之后的视频用的是它，之前的视频要另外判断。

**判断有几台相机**（用户纠正过）：画面里出现多个机位，不等于有多台相机。一个人拍的 vlog 常用「单机位分镜」：拍完一个镜头，把相机挪到下一个位置再拍。只有当同一个连贯动作（倒水、装货）在剪辑里被两个角度接着覆盖时，才能说有第二台。找一段场景按每秒一帧排成联系表来核对。观众评论里说的型号或台数只算线索，要用画面或博主原话核实后，才能标成“有证据”。博主在简介里写的 "a camera" 也是证据。

**反过来也要查：被拍的时候身上还挂着一台**（用户纠正过，2026-10-23，Gangzi 的“40 岁被妈妈催婚”08:19）：固定机位在拍博主时，放大看他领口、胸前、头上有没有挂一台小相机。如果有，紧接着又切到第一视角，回到原地时固定机位还在拍，那就是两台：一台挂身上，一台在三脚架上。先把小黑块和领夹麦分开：领夹麦很小，带一根细线；挂脖相机是块状，第一视角镜头接在后面。还有一条：只要有一个场景三脚架空着，就只能说明那个场景用了一台，不能推出整个频道只有一台。两台通常是为了省时间：外卖、赶路这类场景，把一台相机在挂脖和三脚架之间拆来装去太慢。只有一台的话，配快拆也能凑合。

## 3. 写 gear.json，接进报告

```json
{
 "title": "一个人的拍摄：一半固定机位，一半手持自拍",
 "frames": 33,
 "style": [{"label": "固定机位（三脚架 / 桌面）", "count": 17}, {"label": "手持自拍（广角近景）", "count": 14}],
 "specs": "4K（3840×2160）、30 帧、SDR",
 "items": [
  {"category": "手持主机", "name": "广角云台相机，类似 DJI Osmo Pocket 3", "basis": "自拍画面广角、走路时也很稳", "level": "推断"},
  {"category": "收音", "name": "无线领夹麦，戴在手腕上", "basis": "评论提到 wrist band microphone", "level": "有证据"}
 ],
 "summary": "器材门槛不高……真正花时间的是机位设计和剪辑。"
}
```

在 config 里加上 `"gear": "gear.json"`，`compute_report.py` 会在题材页后面生成一页 `gear` 类型的幻灯片。

### 写法要求

- **`level` 只有两档**：
  - `有证据`：评论原话、简介，或者截帧里能直接看到。
  - `推断`：只能从画面特征和技术参数推出来。
  
  型号永远写成“类似 X”，除非博主自己说过。
- `basis` 控制在 25 个字以内，一行放得下。要写具体的证据，不要写“可能”“应该”。
- `items` 最多 5 条。除了器材，也可以写“声音和字幕”“剪辑风格”这类观众能感知到的做法。比如原声还是旁白、是不是 AI 配音、有没有硬字幕、是不是多机位跳剪。
- `summary` 回答一个问题：照着做需要什么、难在哪里。
- 4K / 30 帧 / SDR 是手机、云台相机、运动相机的常见默认设置，**不能**用它来确定具体型号。
