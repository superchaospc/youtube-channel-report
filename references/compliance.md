# 抖音 / 小红书合规

用户会把竖版 PPT（阅读版做图文、视频版录讲解视频）发到抖音和小红书，所以 deck.json 里所有能看到的文字都要过这一关（用户要求，2026-10-22 起）。三份 PPT 共用一份 deck.json，横版也一起按这个标准写。

`build_decks.sh` 每次生成前会先跑：

```bash
python3 $S/compliance_check.py $W/out/deck.json
```

有命中就打印 `[类别] 位置: …上下文… → 改法`。全部改到 `clean` 再交付。它扫的是标题、卡片、表格、小字说明和演讲者备注。

## 规则和改法

| 类别 | 为什么 | 怎么写 |
|---|---|---|
| 站外平台名 | 平台会给提到 YouTube、TikTok、Instagram 等站外平台的内容限流 | YouTube → 油管；TikTok → 海外短视频平台；Buy Me a Coffee → 海外打赏平台；AdSense → 收款账号。频道名、视频标题照常写 |
| 站外账号和链接 | 小红书把 @handle、网址当作站外引流 | 封面 meta 不放 @handle，只写频道名和截止日期 |
| 引流词 | 导流、引流、私信、微信、二维码都会被判成引流 | 导流 → 带火 / 推荐；导流来源 → 推荐来源 / 带火它的频道 |
| 翻墙 | 不能提怎么访问海外平台 | 整句删掉 |
| 收益承诺 / 网赚 | 抖音严管“月入 X 万”“副业赚钱”这类网赚内容 | “赚了多少” → “收益估算”；封面写明“收益为估算，不构成收益承诺” |
| 极限词 | 小红书限制“最强”“第一”“全网”这类说法 | 换成具体比较，例如“播放更高”“平均每条 4.7 万”。“第一条视频”这类序数不算 |
| 未成年人隐私 | 出镜人是未成年人时，不写家庭隐私细节 | 不写离婚、出轨、赌博、家人真名；只写“单亲家庭”这类概括 |
| 募捐 | 平台限制募捐、众筹内容 | 捐款 → 打赏 / 想支持 |
| 政治敏感 | 评论里的“政府操控”这类说法不要搬进 PPT | 删掉 |

## 写法提醒

- 检查脚本只认关键词，语义上的问题要自己判断。比如不要把苦难写成卖惨，不要渲染未成年人的困境。
- 评论原话要引用的话，先过一遍上面的规则，比如带家人真名的句子不要引用。
- 工作目录里的 CSV、`report.md` 只给用户自己看，不受这些限制。
